Classification & Clustering

Topic 1

K-Nearest Neighbors (KNN)

A lazy, instance-based classifier that votes by proximity

📖 What It Does

KNN classifies an unknown sample by finding the K closest training points (neighbours) in feature space and assigning the majority class among them. "Closest" is usually measured with Euclidean distance.

Euclidean Distance (2-D):
d(P, Q) = √[ (x₂ − x₁)² + (y₂ − y₁)² ]

General n-D form:
d(P, Q) = √[ Σᵢ (pᵢ − qᵢ)² ]

Decision rule: class(x) = mode{ class(neighbour₁), class(neighbour₂), …, class(neighbourₖ) }

Key points:

  • K is a hyperparameter — small K → noisy; large K → over-smooth.
  • Choose odd K for binary problems to avoid ties.
  • Features should be normalised so no single dimension dominates distance.
  • It is non-parametric — no explicit training phase; all computation happens at prediction time.

🖼️ Applying KNN to Image Classification

  1. Feature Extraction: For each image, extract features — e.g., colour histogram, mean intensity, texture descriptors (GLCM), edge counts, or deep features from a CNN.
  2. Build a Training Set: Store feature vectors + labels for all labelled images.
  3. Choose K: Use cross-validation (e.g., K = 3, 5, 7) to find the best K.
  4. Normalise Features: Apply min-max or z-score normalisation so all features are on the same scale.
  5. For a New Image: Extract its feature vector, compute distance to every training sample, pick K closest, and take the majority vote.
  6. Output: The predicted class label for the image (e.g., "cat", "dog", "car").

Topic 2

K-Means Clustering

Unsupervised partitioning of data into K clusters by minimising within-cluster variance

📖 What It Does

K-Means groups N data points into K clusters by iteratively: (1) assigning each point to the nearest centroid, then (2) recomputing centroids as the mean of assigned points. It stops when assignments no longer change (convergence).

Objective (minimise):
J = Σₖ Σ_{x ∈ Cₖ} ‖x − μₖ‖²

Algorithm:
1. Pick K initial centroids (randomly or K-means++).
2. REPEAT:
   a. Assign each point to the nearest centroid.
   b. Recompute each centroid: μₖ = (1/|Cₖ|) Σ_{x ∈ Cₖ} x
3. UNTIL centroids don't change.
  • K must be chosen beforehand (use the elbow method or silhouette score).
  • Sensitive to initialisation — run multiple times and pick the best J.
  • Produces convex (spherical) clusters only.

🔢 Worked Example K = 2, 1-D data

Data points: {2, 3, 8, 9, 10}. Cluster into K = 2.

🖼️ Applying K-Means to an Image (Colour Quantisation)

  1. Reshape the image: Convert the H×W×3 image into a list of N pixels, each a 3-D vector (R, G, B).
  2. Choose K: Decide how many colours to keep (e.g., K = 8).
  3. Run K-Means: Cluster the N pixel vectors into K clusters. Each centroid becomes a representative colour.
  4. Replace pixels: Map every pixel to its cluster centroid colour.
  5. Reshape back: Fold the result back to H×W×3 to get the quantised image.

This reduces the colour palette to exactly K colours — useful for compression or segmentation.

⬡

Morphological Operations

Morphological operations probe a binary (or grayscale) image with a small shape called a structuring element (SE). They are the building blocks for noise removal, shape extraction, and boundary detection. Below, 1 = foreground (white) and 0 = background (black).

Topic 3

Dilation

Grows / expands foreground regions — fills small holes and gaps

📖 What It Does

Dilation adds pixels to object boundaries. For each pixel position, place the structuring element's origin on it. If any foreground pixel of the image overlaps with a "1" in the SE, the output pixel is set to 1.

Set notation:
A ⊕ B = { z | (B̂)_z ∩ A ≠ ∅ }

Rule: Output(x,y) = 1 if ANY pixel under SE is 1 in the input;
             = 0 otherwise.

🖼️ Step-by-Step on an Image

  1. Binarise the image (threshold to 0/1).
  2. Choose a structuring element — shape (cross, square, disk) and size (3×3, 5×5, etc.).
  3. Slide the SE across every pixel in the image (the SE's centre aligns with the current pixel).
  4. At each position, check: does any "1" in the SE overlap a "1" in the image?
  5. If yes → output pixel = 1. If no → output pixel = 0.
  6. The result: objects appear larger; small gaps and holes get filled.

Topic 4

Erosion

Shrinks foreground regions — removes small noise and thin protrusions

📖 What It Does

Erosion removes pixels from object boundaries. At each position, the output pixel is 1 only if all "1" positions of the SE are covered by foreground in the image. Otherwise, it becomes 0.

Set notation:
A ⊖ B = { z | B_z ⊆ A }

Rule: Output(x,y) = 1 if ALL SE "1" pixels match "1" in the input;
             = 0 otherwise.

🖼️ Step-by-Step on an Image

  1. Binarise the image.
  2. Choose a structuring element (same shapes as dilation).
  3. Slide the SE across every pixel position.

  5. If yes → output = 1. If no → output = 0.
  6. Result: objects become smaller; thin bridges and small noise specks vanish.

Topic 5

Opening (Erosion → Dilation)

Removes small bright noise while preserving object shape and size

📖 What It Does

Opening = Erosion followed by Dilation using the same SE. The erosion step removes small noise blobs and thin protrusions; the subsequent dilation restores the remaining objects roughly to their original size. The net effect: small foreground noise is removed, while larger shapes are preserved.

Formula:
A ∘ B = (A ⊖ B) ⊕ B

Properties:
• Anti-extensive: A ∘ B ⊆ A (output ≤ input, never adds pixels beyond original)
• Idempotent: (A ∘ B) ∘ B = A ∘ B (applying twice gives same result)

🖼️ Step-by-Step on an Image

  1. Binarise the image.
  2. Choose a structuring element whose size is larger than the noise you want to remove.
  3. Apply erosion: Small blobs (smaller than the SE) disappear entirely.
  4. Apply dilation with the same SE: Surviving objects regrow to approximately their original size.
  5. Result: Clean image with small foreground noise removed, large shapes intact.

Use case: Remove salt noise (isolated white specks) from a binary image.

Topic 6

Closing (Dilation → Erosion)

Fills small holes and gaps while preserving object shape and size

📖 What It Does

Closing = Dilation followed by Erosion using the same SE. The dilation step fills small dark holes and narrow gaps; the subsequent erosion shrinks the objects back to approximately their original size. Net effect: small background holes inside foreground are filled.

Formula:
A • B = (A ⊕ B) ⊖ B

Properties:
• Extensive: A ⊆ A • B (output ≥ input, never removes original foreground)
• Idempotent: (A • B) • B = A • B
• Closing is the dual of Opening: A • B = (Aᶜ ∘ B)ᶜ

🖼️ Step-by-Step on an Image

  1. Binarise the image.
  2. Choose a structuring element whose size matches the holes/gaps you want to fill.
  3. Apply dilation: Objects expand; small internal holes and narrow gaps get filled.
  4. Apply erosion with the same SE: Objects shrink back to roughly their original size.
  5. Result: Clean image with small background holes filled, object boundaries preserved.

Use case: Fill pepper noise (isolated black specks) inside objects, or close narrow breaks in contours.

⚡ Quick Reference: Opening vs. Closing

Operation Formula Order Removes Preserves Use Case
Opening A ∘ B = (A ⊖ B) ⊕ B Erosion → Dilation Small bright (FG) noise Large FG shapes Salt noise removal
Closing A • B = (A ⊕ B) ⊖ B Dilation → Erosion Small dark (BG) holes Object boundaries Pepper noise, gap filling

💡 Memory trick: Opening = Erosion first → removes small foreground. Closing = Dilation first → fills dark holes.
