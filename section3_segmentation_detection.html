Thresholding

📖 What It Does

Thresholding converts a grayscale image into a binary image by comparing every pixel intensity to a chosen threshold T. Pixels greater than T become white (foreground), and those less than or equal to T become black (background).

g(x, y) = 255 if f(x, y) > T g(x, y) = 0 if f(x, y) ≤ T

🔢 Worked Numerical Example

Given 4×4 image, T = 128

Input pixel values:

Output (T = 128): each pixel → 255 if ≥ 128, else 0

🖼️ Step-by-Step on an Image

  1. Load the image and convert to grayscale.
  2. Choose a threshold T (manually, or via Otsu's method).
  3. Scan every pixel: if intensity ≥ T → set 255; else → set 0.
  4. The result is a binary image separating foreground from background.

Histogram Analysis

📖 What It Does

A histogram counts the frequency of each intensity level (0–255) in a grayscale image. It reveals the distribution of pixel intensities and helps choose thresholds for segmentation. A bimodal histogram (two peaks) suggests a natural threshold exists in the valley between the peaks.

h(k) = number of pixels with intensity k, k = 0, 1, …, 255 p(k) = h(k) / N (normalized histogram, where N = total pixels)

🔢 Worked Numerical Example

3×3 image — build its histogram
012
131
233

Histogram counts (only non-zero levels):

  • h(0) = 1
  • h(1) = 3
  • h(2) = 2
  • h(3) = 3

Total pixels N = 9. Normalized: p(0) = 1/9, p(1) = 3/9 = 1/3, p(2) = 2/9, p(3) = 3/9 = 1/3.

The valley between peaks at 1 and 3 is at intensity 2 → a good threshold would be T = 2.

🖼️ Iterative Center of Mass

To mathematically find the perfect valley between peaks, we calculate the Center of Mass (Mean Intensity) for the dark and light regions using this formula:

μ = Σ (pi × count(pi)) / Σ count(pi)

This calculates the "average brightness" of an entire region by giving more weight to intensities that have higher pixel counts. Here is the full academic loop:

  1. Initial Guess: Pick an initial threshold T0 (usually 127, the literal halfway point of a 0-255 image, or the average brightness of the whole image).
  2. The Split: Separate all pixels into Group 1 (Background: values ≤ T) and Group 2 (Foreground: values > T).
  3. Find Centers: Calculate the mean of Group 1 (μ1) and Group 2 (μ2) using the formula above.
  4. Find Midpoint: Calculate the new threshold: Tnew = (μ1 + μ2) / 2.
  5. The Loop: Check if Tnew == T. If yes: You have found the perfect threshold! Stop. If no: Set T = Tnew and go back to Step 2.

Double Segmentation (Two-Threshold / Band Segmentation)

📖 What It Does

Double segmentation is used when one threshold creates only two regions but the image has 3 meaningful areas.

region 0 (Background): pixels < T1 region 1 (Mid): T1 ≤ pixels < T2 region 2 (Bright): pixels ≥ T2

🔢 Worked Numerical Example

3×3 image, T1 = 50, T2 = 150

Output matrix (region assignments):

🖼️ Step-by-Step on an Image

  1. Load the grayscale image and analyze its histogram.
  2. Identify two valleys (or pick Tlow and Thigh manually).
  3. For each pixel: if Tlow ≤ intensity ≤ Thigh → 255, else → 0.
  4. Output the binary mask highlighting only the band of interest.

Line Detection — Horizontal

📖 What It Does & Mask

Detects horizontal lines (edges running left-to-right) by convolving the image with a mask that responds maximally to a horizontal row of similar pixels bordered by different rows above and below.

222
-1-1-1
R = Σ (mask × neighborhood) If |R| > T → line detected at that pixel.

🔢 Worked Numerical Example

Apply mask to center pixel of this 3×3 patch

200200200
101010

R = (-1)(10) + (-1)(10) + (-1)(10)
  + (2)(200) + (2)(200) + (2)(200)
  + (-1)(10) + (-1)(10) + (-1)(10)
R = -30 + 1200 + (-30) = 1140 → strong horizontal line!

🖼️ Step-by-Step on an Image

  1. Convert image to grayscale.
  2. Pad the image borders (e.g., zero-padding).
  3. Slide the 3×3 mask across every pixel; compute R = Σ(mask × neighborhood).
  4. Take |R| and compare to threshold T.
  5. Mark pixels where |R| > T as detected horizontal line pixels.

Corner Detection — Harris

📖 What It Does

The Harris corner detector finds points where the image intensity changes significantly in all directions.

Let A = Ix², B = Iy², C = Ix·Iy Det = A·B - C² Trace = A + B Corner Response: R = Det - k · (Trace)² where k ≈ 0.04–0.06 R > 0 → Corner, R ≈ 0 → Flat, R < 0 → Edge

🔢 Worked Numerical Example

Suppose at a pixel we have computed:

Σ Ix² = 500,   Σ Iy² = 480,   Σ IxIy = 10,   k = 0.04

det(M) = (500)(480) − (10)² = 240000 − 100 = 239900
trace(M) = 500 + 480 = 980
R = 239900 − 0.04 × (980)² = 239900 − 0.04 × 960400 = 239900 − 38416 = 201484
R ≫ 0 → Corner detected!

🖼️ Step-by-Step on an Image

  1. Convert image to grayscale.
  2. Compute image gradients Ix and Iy (using Sobel or similar).
  3. Compute products Ix², Iy², and Ix·Iy for every pixel.
  4. Apply a Gaussian window to sum these products in a local neighborhood → build M.
  5. Compute R = det(M) − k·(trace(M))² for every pixel.
  6. Threshold R: pixels with R above the threshold are corners.
  7. Apply non-maximum suppression to keep only local maxima.
✏️ Practice Question

At a pixel the gradient sums are: Σ Ix² = 1000, Σ Iy² = 950, Σ IxIy = 5, k = 0.05. Compute R and classify the point as corner, edge, or flat.

Corner Detection — Shi-Tomasi

📖 What It Does

Shi-Tomasi is a modification of Harris that uses the minimum eigenvalue as the corner response. The eigenvalues are calculated using the characteristic equation:

λ² - λ·Trace + Det = 0 R = min(λ₁, λ₂) Corner if R > T

🔢 Worked Numerical Example

Given M at a pixel:

Σ Ix² = 600, Σ Iy² = 550, Σ IxIy = 20

Eigenvalues of M: solve det(M − λI) = 0
λ² − (600+550)λ + (600·550 − 20²) = 0
λ² − 1150λ + (330000 − 400) = 0
λ² − 1150λ + 329600 = 0
λ = (1150 ± √(1322500 − 1318400)) / 2 = (1150 ± √4100) / 2
√4100 ≈ 64.03
λ₁ ≈ 607.0, λ₂ ≈ 543.0
R = min(607.0, 543.0) = 543.0
If T = 100 → R > T → Corner detected!

🖼️ Step-by-Step on an Image

  1. Compute gradients Ix and Iy.
  2. Build the structure tensor M at each pixel (same as Harris).
  3. Compute eigenvalues λ₁, λ₂ of M at each pixel.
  4. Set R = min(λ₁, λ₂).
  5. Threshold: if R > T → mark as corner.
  6. Apply non-maximum suppression & optional minimum distance between corners.
✏️ Practice Question

Corner Detection — ORB (Oriented FAST and Rotated BRIEF)

📖 What It Does

ORB uses FAST to detect corners by classifying pixels in a circle around a center pixel into three categories based on the center pixel's intensity and a given threshold. Then it adds orientation and a rotated BRIEF descriptor.

Range = [intensity - threshold, intensity + threshold] Category A (Darker): Value ≤ (intensity - threshold) Category B (Similar): Inside the Range Category C (Brighter): Value ≥ (intensity + threshold)

🔢 Worked Numerical Example

Center pixel intensity = 100, threshold = 20

Range = [100 - 20, 100 + 20] = [80, 120]
A ≤ 80   —   B (between)   —   C ≥ 120

Position12345678910
Value7570606060708595110130
CategoryAAAAAABBBC

If enough contiguous pixels are in Category A or Category C, it is detected as a corner.

🖼️ Step-by-Step on an Image

  1. Build an image pyramid (multi-scale) for scale invariance.
  2. At each scale, apply FAST corner detection with threshold t.
  3. Apply Harris score to rank FAST corners; keep top-K.
  4. Compute orientation for each keypoint using intensity centroid.
  5. Generate rotation-invariant BRIEF descriptors using the computed orientation.
  6. Use descriptors for matching between images (Hamming distance).

Point Detection (Isolated Point Detection)

📖 What It Does & Mask

Detects isolated points — single pixels that are significantly different from all their neighbors. The mask is essentially a Laplacian: the center pixel gets a large positive weight (8), and all 8 neighbors get −1. The sum of the mask is zero, so uniform regions yield zero response.

-1-1-1
-18-1
-1-1-1
R = |Σ (mask × neighborhood)| If R > T → isolated point detected.

🔢 Worked Numerical Example

3×3 patch with an isolated bright point
101010
1025010
101010

R = (-1)(10)×8 + (8)(250)
R = −80 + 2000 = 1920
|R| = 1920 ≫ T → Isolated point detected!

🖼️ Step-by-Step on an Image

  1. Convert image to grayscale and pad borders.
  2. Slide the 3×3 point-detection mask over every pixel.
  3. Compute R = Σ(mask × neighborhood) at each position.
  4. Take |R| and compare to threshold T.
  5. Pixels with |R| > T are marked as isolated points.

Edge Detection — Sobel Operator

📖 What It Does & Masks

The Sobel operator computes the gradient magnitude of the image using two 3×3 kernels: one for horizontal changes (Gx) and one for vertical changes (Gy). Edges are located where the gradient magnitude is large.

Gx (Horizontal Gradient)

-101
-202
-101

Gy (Vertical Gradient)

-1-2-1
000
121
G = √(G_x² + G_y²) (gradient magnitude) θ = atan2(G_y, G_x) (gradient direction) Approximate: G ≈ |G_x| + |G_y|

🔢 Worked Numerical Example

Apply Sobel to center pixel of this 3×3 patch
100100200
100100200
100100200

Gx:
= (-1)(100) + (0)(100) + (1)(200)
+ (-2)(100) + (0)(100) + (2)(200)
+ (-1)(100) + (0)(100) + (1)(200)
= (-100+200) + (-200+400) + (-100+200) = 100 + 200 + 100 = 400

Gy:
= (-1)(100) + (-2)(100) + (-1)(200)
+ (0)(100) + (0)(100) + (0)(200)
+ (1)(100) + (2)(100) + (1)(200)
= (-100-200-200) + 0 + (100+200+200) = -500 + 500 = 0

G = √(400² + 0²) = √160000 = 400
θ = atan2(0, 400) = 0° → vertical edge (gradient points horizontally)

🖼️ Step-by-Step on an Image

  1. Convert image to grayscale.
  2. Optionally smooth with a Gaussian filter to reduce noise.
  3. Convolve the image with the Gx kernel → horizontal gradient.
  4. Convolve the image with the Gy kernel → vertical gradient.
  5. Compute gradient magnitude G = √(Gx² + Gy²) at each pixel.
  6. Optionally compute gradient direction θ = atan2(Gy, Gx).
  7. Compute the average of the gradient magnitude: T = Avg(G).
  8. Apply thresholding on G(M) using T to obtain the binary edge map.
