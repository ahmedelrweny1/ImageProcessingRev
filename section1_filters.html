Mode Filter

Non-linear order-statistics filter

Description & Formula

The Mode Filter replaces the centre pixel with the most frequently occurring value in its neighbourhood. It is effective against salt-and-pepper noise while preserving edges better than mean-based filters. If multiple modes exist, common implementations pick the smallest mode or the centre value itself.

output(x, y) = mode{ g(s, t) | (s, t) ∈ Sxy }
Worked Example (3 × 3)
121515
201815
222015

Neighbourhood values: {12, 15, 15, 20, 18, 15, 22, 20, 15}

Frequency count: 15 appears 4 times (most frequent).

Result: Centre pixel → 15

How to Apply on an Image
  1. Choose a kernel size (e.g., 3×3).
  2. Pad the image borders (zero-pad or replicate).
  3. Slide the kernel across every pixel.
  4. Collect all pixel values inside the kernel window.
  5. Compute the mode (most frequent value).
  6. Replace the centre pixel with the mode.
  7. Move to the next pixel and repeat until the entire image is processed.
Practice Question

Q:

Given the 3×3 neighbourhood: {5, 8, 5, 3, 5, 8, 8, 8, 3}, what is the output of the Mode filter?

Answer: 8 appears 4 times, 5 appears 3 times, 3 appears 2 times. Mode = 8.

Median Filter

Non-linear order-statistics filter

Description & Formula

The Median Filter replaces the centre pixel with the median (middle value) of sorted neighbourhood values. It excels at removing salt-and-pepper noise while preserving edges far better than averaging filters.

output(x, y) = median{ g(s, t) | (s, t) ∈ Sxy }
Worked Example (3 × 3)
102015
2525518
121422

Sorted: {10, 12, 14, 15, 18, 20, 22, 25, 255}

Middle value (5th of 9) = 18. The noisy 255 is eliminated!

How to Apply on an Image
  1. Choose a kernel size (e.g., 3×3, 5×5 — always odd).
  2. Pad the image borders appropriately.
  3. For each pixel, extract the neighbourhood values.
  4. Sort all values in ascending order.
  5. Pick the middle value (position ⌈n/2⌉ for n values).
  6. Replace the centre pixel with this median value.
  7. Repeat for every pixel in the image.
Practice Question

Q:

A 3×3 window yields these pixel values: {100, 2, 98, 5, 0, 97, 99, 3, 96}. What does the Median filter output? Is it effective here?

Answer: Sorted: {0, 2, 3, 5, 96, 97, 98, 99, 100}. Median = 96. Yes — the low-value impulses (0, 2, 3, 5) are ignored.

Mid-point Filter

Order-statistics filter

Description & Formula

The Mid-point Filter computes the average of the maximum and minimum pixel values in the neighbourhood. It works best for uniformly distributed and Gaussian noise.

output(x, y) = ½ × [ max(Sxy) + min(Sxy) ]
Worked Example (3 × 3)
304550
554060
357025

Min = 25, Max = 70

Mid-point = ½ × (70 + 25) = 47.5 ≈ 48

How to Apply on an Image
  1. Define the kernel size (e.g., 3×3).
  2. Pad the image borders.
  3. For each pixel, gather neighbourhood values.
  4. Find the maximum and minimum values.
  5. Compute their average: (max + min) / 2.
  6. Replace the centre pixel with this result.
  7. Repeat across the entire image.
Practice Question

Q:

Neighbourhood values: {10, 50, 30, 80, 40, 20, 60, 90, 70}. What is the Mid-point filter output?

Answer: Min = 10, Max = 90. Mid-point = (10 + 90) / 2 = 50.

Alpha-Trimmed Mean Filter

Compromise between mean and median

Description & Formula

Sort all mn values in the window, then delete the d/2 lowest and d/2 highest values (total d trimmed). Average the remaining mn − d values. When d = 0 it reduces to the arithmetic mean; when d = mn − 1 it becomes the median. Useful for mixed noise (e.g., Gaussian + salt-and-pepper).

output(x, y) = 1 / (mn − d) × Σ gr(s, t)
where gr are the remaining values after trimming d/2 from each end of the sorted list.
Worked Example (3 × 3, d = 4)
05055
605258
2554853

Sorted: {0, 48, 50, 52, 53, 55, 58, 60, 255}

Trim d/2 = 2 from each end → remove {0, 48} and {60, 255}.

Remaining: {50, 52, 53, 55, 58} → Sum = 268

Average = 268 / 5 = 53.6 ≈ 54

How to Apply on an Image
  1. Choose kernel size (mn) and trimming parameter d (even number, 0 ≤ d ≤ mn − 1).
  2. Pad image borders.
  3. For each pixel, extract and sort the neighbourhood values.
  4. Remove the d/2 smallest and d/2 largest values.
  5. Compute the arithmetic mean of the remaining (mn − d) values.
  6. Replace the centre pixel.
  7. Repeat for every pixel.
Practice Question

Q:

Sorted 3×3 window: {2, 10, 12, 14, 15, 16, 18, 20, 250}. With d = 2, what is the alpha-trimmed mean?

Answer: Remove 1 from each end: remove {2} and {250}. Remaining: {10, 12, 14, 15, 16, 18, 20}. Sum = 105. Mean = 105 / 7 = 15.

Mean / Average / Blur Filter

Box filter — linear smoothing

Description & Formula

The simplest smoothing filter. Each pixel is replaced by the arithmetic mean of its neighbours. It reduces Gaussian noise effectively but blurs edges. The 3×3 kernel has all weights = 1/9.

output(x, y) = (1 / mn) × Σ g(s, t) for (s,t) ∈ Sxy

Kernel (3×3):   ¹⁄₉ × | 1 1 1 |
                    | 1 1 1 |
                    | 1 1 1 |
Worked Example (3 × 3)
102030
405060
708090

Sum = 10+20+30+40+50+60+70+80+90 = 450

Mean = 450 / 9 = 50

How to Apply on an Image
  1. Create the averaging kernel (e.g., 3×3 of all 1/9).
  2. Pad the image borders.
  3. Convolve: slide the kernel over each pixel.
  4. At each position, multiply corresponding values and sum → divide by mn.
  5. Write the result to the output image.
  6. Repeat for all pixels. Larger kernels → more blur.
Practice Question

Q:

Apply a 3×3 mean filter to the centre pixel of: {5, 10, 15, 20, 25, 30, 35, 40, 45}. What is the result?

Answer: Sum = 5+10+15+20+25+30+35+40+45 = 225. Mean = 225 / 9 = 25.

Max Filter

Order-statistics filter — dilation

Description & Formula

Replaces the centre pixel with the maximum value in the neighbourhood. Useful for removing pepper noise (dark spots) and performing morphological dilation. It brightens the image.

output(x, y) = max{ g(s, t) | (s, t) ∈ Sxy }
Worked Example (3 × 3)
100110105
095108
10211598

Values: {100, 110, 105, 0, 95, 108, 102, 115, 98}

Max = 115. The pepper noise (0) is ignored.

How to Apply on an Image
  1. Define the kernel size.
  2. Pad image borders.
  3. For each pixel, extract neighbourhood values.
  4. Find the maximum value.
  5. Replace the centre pixel with max.
  6. Repeat for every pixel.
Practice Question

Q:

Neighbourhood: {45, 0, 60, 55, 0, 50, 48, 0, 52}. What does the Max filter return? What type of noise does it help with?

Answer: Max = 60. The Max filter helps remove pepper noise (the dark 0-value pixels).

Min Filter

Order-statistics filter — erosion

Description & Formula

Replaces the centre pixel with the minimum value in the neighbourhood. Useful for removing salt noise (bright spots) and performing morphological erosion. It darkens the image.

output(x, y) = min{ g(s, t) | (s, t) ∈ Sxy }
Worked Example (3 × 3)
505560
4825552
585357

Values: {50, 55, 60, 48, 255, 52, 58, 53, 57}

Min = 48. The salt noise (255) is eliminated.

How to Apply on an Image
  1. Define the kernel size.
  2. Pad image borders.
  3. For each pixel, extract neighbourhood values.
  4. Find the minimum value.
  5. Replace the centre pixel with min.
  6. Repeat for every pixel.
Practice Question

Q:

Neighbourhood: {120, 255, 130, 125, 255, 128, 122, 255, 135}. What does the Min filter output? What noise does it address?

Answer: Min = 120. It removes salt noise (the bright 255 pixels).

Harmonic Mean Filter

Mean filter variant

Description & Formula

Computes the harmonic mean of the neighbourhood. It works well for salt noise and Gaussian noise but fails for pepper noise (any zero value makes the output zero).

output(x, y) = mn / Σ [ 1 / g(s,t) ]    for (s,t) ∈ Sxy
Worked Example (3 × 3)
102030
405060
203040

Σ(1/g) = 1/10 + 1/20 + 1/30 + 1/40 + 1/50 + 1/60 + 1/20 + 1/30 + 1/40

= 0.1 + 0.05 + 0.0333 + 0.025 + 0.02 + 0.0167 + 0.05 + 0.0333 + 0.025 = 0.3533

Harmonic mean = 9 / 0.3533 = 25.47 ≈ 25

How to Apply on an Image
  1. Choose kernel size and pad borders.
  2. For each pixel, extract neighbourhood values.
  3. Compute the reciprocal (1/value) of each pixel.
  4. Sum all reciprocals.
  5. Divide mn (number of pixels) by that sum.
  6. Replace the centre pixel with the result.
  7. Repeat. Warning: fails if any pixel = 0.
Practice Question

Q:

A 3×3 window has values: {5, 10, 20, 10, 5, 20, 10, 20, 5}. Compute the harmonic mean. Why can't this filter handle pepper noise?

Answer: Σ(1/g) = 3×(1/5) + 3×(1/10) + 3×(1/20) = 0.6 + 0.3 + 0.15 = 1.05. HM = 9/1.05 ≈ 8.57. It fails on pepper noise because if any pixel = 0, 1/0 is undefined (infinity), making the output 0.

Contra-Harmonic Mean Filter

Order-controlled mean filter

Description & Formula

A powerful filter controlled by parameter Q (order). Positive Q eliminates pepper noise; negative Q eliminates salt noise. At Q = 0 it becomes the arithmetic mean; at Q = −1 it becomes the harmonic mean.

output(x, y) = Σ g(s,t)Q+1 / Σ g(s,t)Q    for (s,t) ∈ Sxy
Worked Example (3 × 3, Q = 1)
234
304
532

Numerator Σ gQ+1 = Σ g² = 4+9+16+9+0+16+25+9+4 = 92

Denominator Σ gQ = Σ g¹ = 2+3+4+3+0+4+5+3+2 = 26

Result = 92 / 26 = 3.54 ≈ 4 (pepper noise 0 is suppressed)

How to Apply on an Image
  1. Choose kernel size and the order Q.
  2. Pad image borders.
  3. For each pixel, extract neighbourhood values.
  4. Compute Σ gQ+1 (numerator).
  5. Compute Σ gQ (denominator).
  6. Divide numerator / denominator → output pixel.
  7. Repeat. Use Q > 0 for pepper noise, Q < 0 for salt noise.
Practice Question

Q:

3×3 window: {10, 10, 10, 10, 10, 10, 10, 10, 10} with Q = 2. What is the result? What happens when all values are identical?

Answer: Numerator = 9 × 10³ = 9000. Denominator = 9 × 10² = 900. Result = 9000/900 = 10. When all values are identical, the filter always returns that value regardless of Q.

Weighted Mean Filter

Weighted averaging — linear smoothing

Description & Formula

Like the mean filter, but each neighbour is given a different weight. The centre pixel usually receives the highest weight, giving it more influence. This provides smoother results than the box filter while still reducing noise.

output(x, y) = Σ w(s,t) · g(s,t) / Σ w(s,t)

Common 3×3 kernel:   ¹⁄₁₆ × | 1 2 1 |
                           | 2 4 2 |
                           | 1 2 1 |
Worked Example (3 × 3)
102030
405060
708090

Weights: 1,2,1,2,4,2,1,2,1 (sum = 16)

Weighted sum = 1×10 + 2×20 + 1×30 + 2×40 + 4×50 + 2×60 + 1×70 + 2×80 + 1×90

= 10 + 40 + 30 + 80 + 200 + 120 + 70 + 160 + 90 = 800

Result = 800 / 16 = 50

How to Apply on an Image
  1. Define the weight kernel (e.g., the 1-2-1 / 2-4-2 / 1-2-1 kernel).
  2. Pad the image borders.
  3. For each pixel, multiply each neighbour by its corresponding weight.
  4. Sum all weighted values.
  5. Divide by the sum of weights (normalisation).
  6. Replace the centre pixel with the result.
  7. Repeat for the entire image.
Practice Question

Q:

Using weights [1,2,1; 2,4,2; 1,2,1] and pixel values [100,100,100; 100,200,100; 100,100,100], compute the weighted mean. Why is this better than a simple average?

Answer: Weighted sum = 8×(1 or 2)×100 + 4×200 = (1+2+1+2+2+1+2+1)×100 + 4×200 = 1200+800 = 2000. Wait — let's recalculate: 1×100+2×100+1×100+2×100+4×200+2×100+1×100+2×100+1×100 = 100+200+100+200+800+200+100+200+100 = 2000. Sum of weights = 16. Result = 2000/16 = 125. It is better because the centre pixel (200) has more influence, preserving local detail better than a plain average which would give (8×100+200)/9 ≈ 111.

Gaussian Filter

Gaussian smoothing / blur

Description & Formula

A weighted smoothing filter whose weights follow a 2D Gaussian distribution. Provides better smoothing than box filters with less ringing. Controlled by σ (standard deviation) — larger σ = more blur.

G(x, y) = (1 / 2πσ²) × e−(x²+y²) / 2σ²

Approx. 3×3 kernel (σ ≈ 0.85):   ¹⁄₁₆ × | 1 2 1 |
                                    | 2 4 2 |
                                    | 1 2 1 |
Worked Example (3 × 3)
202530
354045
505560

Using kernel ¹⁄₁₆ × [1,2,1; 2,4,2; 1,2,1]:

Sum = 1×20 + 2×25 + 1×30 + 2×35 + 4×40 + 2×45 + 1×50 + 2×55 + 1×60

= 20+50+30+70+160+90+50+110+60 = 640

Result = 640 / 16 = 40

How to Apply on an Image
  1. Choose σ and compute the Gaussian kernel (or use a standard approximation).
  2. Normalise kernel values so they sum to 1.
  3. Pad image borders.
  4. Convolve: for each pixel, multiply neighbours by kernel weights, sum, and write result.
  5. Optionally separate into two 1D passes (row then column) for efficiency — Gaussian is separable.
  6. Repeat for all pixels.
Practice Question

Q:

Why is the Gaussian filter called "separable," and how does this property speed up computation for large kernels?

Answer: A 2D Gaussian can be decomposed into the product of two 1D Gaussians: G(x,y) = G(x) × G(y). Instead of n² multiplications per pixel (for an n×n kernel), you only need 2n multiplications (one horizontal pass + one vertical pass). For a 7×7 kernel, this means 14 ops instead of 49 — a 3.5× speedup.

High Pass Filter

Sharpening / edge detection — spatial domain

Description & Formula

A High Pass Filter allows high-frequency components (edges, details) to pass while attenuating low-frequency (smooth) areas. It is the complement of a low-pass filter: HPF = Original − LPF. The kernel sums to 0 (or near 0).

Basic 3×3 HPF kernel:   | -1 -1 -1 |
                       | -1  8 -1 |
                       | -1 -1 -1 |
(Sum of all weights = 0)
Worked Example (3 × 3)
505050
5020050
505050

Result = (−1)×50×8 + 8×200 = −400 + 1600 = 1200

Clamped to [0, 255] → 255

The bright centre pixel stands out — the filter detects it as an edge/detail.

How to Apply on an Image
  1. Define the HPF kernel (weights sum to 0).
  2. Pad the image borders.
  3. Convolve the kernel with the image.
  4. Results may be negative — clamp or rescale to [0, 255].
  5. The output highlights edges and fine details.
  6. Optionally add back to the original for sharpening: sharp = original + k × HPF_result.
Practice Question

Q:

Apply the HPF kernel [-1,-1,-1; -1,8,-1; -1,-1,-1] to a region where all pixels = 100. What is the output? What does this tell you?

Answer: Output = (-1)×100×8 + 8×100 = -800+800 = 0. In a flat (uniform) region, the HPF gives 0 — it only responds to changes (edges), confirming it filters out low frequencies.
13

Low Pass Filter

Smoothing filter

Description & Formula

A Low Pass Filter allows low-frequency components (smooth regions) to pass while attenuating high-frequency components (edges, noise). The simplest LPF is the box/mean filter. All kernel values are positive and sum to 1.

3×3 LPF (box):   ¹⁄₉ × | 1 1 1 |
                      | 1 1 1 |
                      | 1 1 1 |
(Sum of all weights = 1, all non-negative)
Worked Example (3 × 3)
1020015
1218018
1419020

Sum = 10+200+15+12+180+18+14+190+20 = 659

Mean = 659 / 9 = 73.2 ≈ 73

The sharp edges (10 vs 200) are smoothed out.

How to Apply on an Image
  1. Choose an LPF kernel (box, Gaussian, or custom — all positive, summing to 1).
  2. Pad the image borders.
  3. Convolve the kernel with each pixel neighbourhood.
  4. Write the result to the output image.
  5. Larger kernels produce more smoothing (more blur).
  6. Can also be done in the frequency domain: multiply by a low-pass transfer function.
Practice Question

Q:

What is the relationship between LPF and HPF? If you have the original image I and the LPF result L, how do you get the HPF result?

Answer: HPF = I − LPF. The high-pass result is the original image minus the low-pass (smoothed) version. This is because LPF keeps the smooth parts, so subtracting it leaves only the edges/details.

Laplacian Filter (Sharpening)

2nd-order derivative filter

Description & Formula

The Laplacian is a 2nd-order derivative operator that detects regions of rapid intensity change. It is isotropic (rotation-invariant). Since it highlights edges in all directions, it is used for sharpening: sharpened = original − Laplacian (when centre is negative) or original + Laplacian (when centre is positive).

∇²f = ∂²f/∂x² + ∂²f/∂y²

Kernel (4-connected):   |  0 -1  0 |     Kernel (8-connected):   | -1 -1 -1 |
                       | -1  4 -1 |                       | -1  8 -1 |
                       |  0 -1  0 |                       | -1 -1 -1 |
Worked Example (3 × 3, 4-connected kernel)
101010
108010
101010

Laplacian = 0×10 + (−1)×10 + 0×10 + (−1)×10 + 4×80 + (−1)×10 + 0×10 + (−1)×10 + 0×10

= 0 − 10 + 0 − 10 + 320 − 10 + 0 − 10 + 0 = 280

Sharpened = 80 − (−1)×… Actually with positive centre: sharp = original + Laplacian output isn't used directly. Instead:

Since the centre coefficient is positive (+4), sharpened = original + Laplacian: not needed here. The Laplacian output 280 indicates a strong edge at the centre pixel.

How to Apply on an Image
  1. Choose the Laplacian kernel (4-connected or 8-connected).
  2. Pad image borders.
  3. Convolve the kernel with the image to get the Laplacian result L.
  4. For sharpening: if the centre coefficient is positive, compute sharp = original + L; if negative, compute sharp = original − L.
  5. Clamp results to [0, 255].
  6. The Laplacian alone gives edges; combined with the original gives a sharpened image.
Practice Question

Q:

Apply the 4-connected Laplacian [0,-1,0; -1,4,-1; 0,-1,0] to a flat region where all pixels = 50. What is the Laplacian output? What does this mean?

Answer: L = 0×50 + (-1)×50 + 0×50 + (-1)×50 + 4×50 + (-1)×50 + 0×50 + (-1)×50 + 0×50 = -50-50+200-50-50 = 0. In a flat region the Laplacian is zero — it only responds to intensity changes, confirming it's a derivative operator.

Sobel Filter

1st-order derivative — edge detection

Description & Formula

The Sobel operator computes the gradient magnitude using two 3×3 kernels — one for horizontal edges (Gx) and one for vertical edges (Gy). It adds a smoothing component (weighted centre row/column) making it less sensitive to noise than Prewitt.

Gx = | -1 0 +1 |     Gy = | -1 -2 -1 |
     | -2 0 +2 |          |  0  0  0 |
     | -1 0 +1 |          | +1 +2 +1 |

|G| = √(Gx² + Gy²)    or approximated as   |G| ≈ |Gx| + |Gy|
Worked Example (3 × 3)
100100100
100100200
100100200

Gx = (−1×100)+(0×100)+(1×100) + (−2×100)+(0×100)+(2×200) + (−1×100)+(0×100)+(1×200)

= (−100+0+100) + (−200+0+400) + (−100+0+200) = 0 + 200 + 100 = 300

Gy = (−1×100)+(−2×100)+(−1×100) + (0×100)+(0×100)+(0×200) + (1×100)+(2×100)+(1×200)

= (−100−200−100) + (0+0+0) + (100+200+200) = −400 + 0 + 500 = 100

|G| = √(300² + 100²) = √(90000 + 10000) = √100000 ≈ 316 → clamped to 255

How to Apply on an Image
  1. Pad the image borders.
  2. Convolve the image with Gx to get horizontal gradient.
  3. Convolve the image with Gy to get vertical gradient.
  4. Compute gradient magnitude: |G| = √(Gx² + Gy²) per pixel.
  5. Optionally compute gradient direction: θ = arctan(Gy/Gx).
  6. Clamp to [0, 255] or threshold to create a binary edge map.
Practice Question

Q:

Apply Sobel Gx to a uniform patch where all 9 pixels = 50. What is Gx? Why does this make sense?

Answer: Gx = (-1-2-1)×50 + (0+0+0)×50 + (1+2+1)×50 = -200 + 0 + 200 = 0. There is no horizontal gradient (no edge) in a uniform patch, so the derivative is zero. This is expected — Sobel only responds to intensity changes.
16

Prewitt Filter

1st-order derivative — edge detection

Description & Formula

The Prewitt operator is similar to Sobel but uses equal weights (no emphasis on the centre row/column). It computes the gradient using two 3×3 kernels. It is slightly more sensitive to noise than Sobel but computationally simpler.

Gx = | -1 0 +1 |     Gy = | -1 -1 -1 |
     | -1 0 +1 |          |  0  0  0 |
     | -1 0 +1 |          | +1 +1 +1 |

|G| = √(Gx² + Gy²)
Worked Example (3 × 3)
5050150
5050150
5050150

Gx = (−1×50)+(0×50)+(1×150) + (−1×50)+(0×50)+(1×150) + (−1×50)+(0×50)+(1×150)

= 100 + 100 + 100 = 300

Gy = (−1×50)+(−1×50)+(−1×150) + 0+0+0 + (1×50)+(1×50)+(1×150)

= (−50−50−150) + 0 + (50+50+150) = −250 + 250 = 0

|G| = √(300² + 0²) = 300 → clamped to 255

Strong vertical edge detected (Gx is high), no horizontal edge (Gy = 0).

How to Apply on an Image
  1. Pad the image borders.
  2. Convolve with the Prewitt Gx kernel for horizontal edges.
  3. Convolve with the Prewitt Gy kernel for vertical edges.
  4. Combine: |G| = √(Gx² + Gy²), or use |Gx| + |Gy|.
  5. Clamp to [0, 255].
  6. Optionally threshold to create a binary edge image.
Practice Question

Q:

What is the key difference between Sobel and Prewitt kernels? When would you prefer Sobel over Prewitt?

Answer: The Sobel kernel uses weights [1, 2, 1] giving more weight to the centre row/column, which provides a small amount of smoothing. Prewitt uses equal weights [1, 1, 1]. Prefer Sobel when the image has noise, because the extra smoothing reduces noise sensitivity while still detecting edges accurately.
